# Machine Learning to Identify Encryption Protocols

This project uses machine learning to identify which encryption protocol
(AES, DES, or RC5) was used by analyzing encrypted text.

## Project Contents
- `code/` – Jupyter Notebook with data generation, training, and evaluation
- `report/` – Full project report (PDF)

## Models Used
- Random Forest
- XGBoost
- Linear SVC

## Key Results
- Up to 98% accuracy on structured text
- Accuracy drops on random text
- RC5 is easier to classify than AES and DES

## Technologies
- Python
- scikit-learn
- XGBoost
- Jupyter Notebook
